Similar-neuron merging (MLP intermediate dim)

          

            Two neurons merge only when both their gate_proj and up_proj rows are highly
            similar — safe without calibration data because that jointly implies near-identical
            activations for any input. Measured on synthetic weights: ~0.3% median output error
            at 0.998 similarity, ~1.3% at 0.97. Default 0.98 is conservative.
          

          

            

              
              
            

            

              
              
            

            

              
              
            

          

          
          

            
            

              
            

          

          
          
          
          

          

          

        


        

          
SVD weight compression

          

            Denoise: replaces a matrix with its best low-rank reconstruction at the
            same shape — never breaks compatibility, doesn't shrink the file, removes
            low-signal noise. Factorize: splits a matrix into two smaller ones —
            genuine size reduction, but the result needs custom loading code (a
            svd_manifest.json documents exactly how).
          

          

            

              
              
            

            

              
              
            

            

              
              
            

          

          
          
          
          

        


        

          
Distillation recovery

          

            Generates a config for the existing distillation trainer (task: distill) —
            teacher/student KL distillation, already fully implemented. This just pre-fills it:
            student = your compressed model, teacher = the original.
